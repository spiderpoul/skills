# Каталог скиллов

| Имя | Задача | Владелец |
|---|---|---|
| [ai-ready-check](ai-ready-check/SKILL.md) | аудит среды агентной разработки с доказательствами и минимальным планом улучшений | [@spiderpoul](https://github.com/spiderpoul) |

Каждый каталог содержит самостоятельный `SKILL.md` с `name` и `description`. Устанавливайте каталог целиком: связанные `references/`, `scripts/` и `assets/`, если они есть, являются частью скилла. `agents/` содержит необязательные метаданные клиента.

Установка и примеры запуска: [основной README](../README.md). Требования к новым процедурам: [CONTRIBUTING.md](../CONTRIBUTING.md).
